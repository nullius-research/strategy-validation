# Watchlist

Een ticker per regel, beginnend met een streepje. Yahoo Finance notatie.

Steekproefgrootte gaat voor alles. Tien tickers levert geen bruikbare n op.
Onder de 200 trades is een uitslag niet interpreteerbaar, en om een edge van
0.05R te kunnen zien heb je er eerder duizend nodig. Test op het universum als
geheel, nooit per ticker.

historie ophalen van de winnaars van vandaag maakt elke long only strategie er
beter uit zien dan hij was. yfinance kan dit niet voor je oplossen.
